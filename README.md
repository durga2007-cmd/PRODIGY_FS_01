# PRODIGY_FS_01
🔐 Secure Authentication System
📌 About
A Java Web Application for secure user authentication built using Eclipse IDE, Apache Tomcat, and MySQL.

🚀 Quick Setup
Import in Eclipse: File → Import → Existing Projects into Workspace

Configure Database: Run database/setup.sql

Add Libraries: Copy JAR files to WEB-INF/lib/

Run: Right-click project → Run on Server → Tomcat

🗂️ Project Structure
text
src/
├── com.auth.controller/  # Servlets

└── com.auth.util/        # Helper classes
WebContent/
├── login.jsp
├── register.jsp
├── dashboard.jsp
